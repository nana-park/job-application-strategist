# Company Report

기업 조사, 채용공고 분석, 지원 전략과 면접 자료를 기업별로 모아 보는 **Career Workspace**입니다. 실제 지원 준비에 사용하는 정적 웹 도구입니다.

**[사이트 열기 →](https://nana-park.github.io/company-report/)**

![Career Workspace의 기업 목록 화면](docs/images/career-workspace.jpg)

*실제 공개 사이트의 홈 화면입니다. 기업명과 조사 기준일만 표시하며, 잠금 해제된 개인 지원 자료는 포함하지 않습니다.*

## 할 수 있는 일

- 기업 목록을 최근 조사순 또는 가나다순으로 정렬합니다.
- 기업별 조사 보고서와 채용공고별 분석 자료를 찾아봅니다.
- 지원 전략과 면접 준비 자료를 연결해 확인합니다. 보호된 자료는 별도의 잠금 해제 절차를 사용합니다.
- 보고서의 출처와 기준일을 확인하고 인쇄용 화면으로 읽습니다.

## 구성과 실행

HTML, CSS, JavaScript로 구성되어 있으며 별도의 빌드 과정 없이 GitHub Pages에서 제공합니다. 사이트는 저장된 보고서를 보여 주며, 이 저장소 자체에서 AI 조사를 자동 실행하지는 않습니다.

- `index.html`: 기업 목록과 정렬
- `company-*/`: 기업 보고서, 채용공고 분석 및 지원 자료
- `assets/fonts/`: 로컬 글꼴
- `tools/`: 자료 보호 설정 도구와 합성 데이터 기반 테스트 페이지

로컬에서는 저장소 루트를 정적 HTTP 서버로 열어 확인할 수 있습니다. GitHub Pages 배포 소스는 `main` 브랜치의 루트(`/`)이며 `.nojekyll`을 사용합니다. 내부 링크와 이미지 경로는 상대경로입니다.

## 공개 화면과 테스트 자료

실제 서비스와 개발용 샘플은 구분됩니다. `tools/` 아래의 `synthetic`·`demo` 테스트 페이지에는 합성 데이터와 공개 테스트용 키가 사용되므로 해당 표기를 유지합니다. 개인 문서, 실제 비밀번호와 비밀키는 테스트 페이지나 공개 저장소에 넣지 않습니다.

저장소 이름 변경 후 사이트 주소는 `https://nana-park.github.io/company-report/`입니다. 이전 `company-report-demo/` Pages 주소를 저장해 두었다면 새 주소로 갱신해 주세요.
